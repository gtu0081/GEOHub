# Contributing

Thank you for your interest in Yao GEO. External code merges are temporarily paused while the Contributor License Agreement receives legal review.

You may open an issue with a reproducible bug report, design observation, or documentation suggestion. Do not include confidential information, customer data, credentials, proprietary platform outputs, or content you lack permission to share.

Maintainers may discuss and triage proposals during the pause. A proposal, review, or discussion does not imply acceptance. When code contributions reopen, changes will be expected to target `main`, include focused tests, preserve protocol compatibility, and pass `make verify`.

This project does not provide legal advice. Contributors should obtain their own advice when needed.
